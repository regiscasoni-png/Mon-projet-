# Listes quotidiennes de prospects

Une liste par jour et par zone : `AAAA-MM-JJ-zone.md`.

Pour lancer la journée, indique simplement : **commune (ou quartier) + rayon**,
et éventuellement un type de cible prioritaire.

Exemples :
- « Aujourd'hui : Aubagne et 10 km autour »
- « Ce matin je suis sur le centre-ville de Toulon, cible commerces »
- « Zone du jour : Salon-de-Provence, plutôt artisans du bâtiment »

Chaque fiche prospect contient :

| Champ | Contenu |
|---|---|
| Entreprise | Nom, activité, adresse, SIREN si vérifié |
| Contact | Téléphone pro public, site/réseaux, dirigeant si identifié |
| Constat | Le signal observé (pas de site, réseaux morts, invisible sur Google…) |
| Formation à proposer | Formation d'appel + formations secondaires |
| Angle | La phrase d'accroche adaptée à ce prospect |
| Priorité | A / B / C |
